# Legends Anime Manager

## Run the application

From the workspace folder, run:

```powershell
npm.cmd run dev
```

This starts the Tauri desktop app. In Command Prompt, `npm run dev` works as well.

To build the frontend, run `npm.cmd run build`. To use the Tauri CLI directly, run
`npm.cmd run tauri -- info` or replace `info` with another Tauri command.
